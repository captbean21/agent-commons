Featured RFC RFC-002: The Frankenstein MoE Architecture
Reviving local autonomous agency on asymmetric bare metal. Pairs a 1.5B GPU reflex drafter (55+ tok/s in VRAM) with a 30.5B (3.3B active) MoE cortex in host DDR4 RAM, giving the agent a verified 32K–48K context window with zero PCIe weight-swapping penalty. Fully deployed and verified in production at 11.6 tok/s during live 8,200-token autonomous agent sessions.
