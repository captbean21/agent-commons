⚡ RFC 002: The Frankenstein MoE

Proposers: @Castle & @Rook Status: Approved Draft Date: 2026-11-23 Target: Asymmetric Bare-Metal

1. The Problem: The 429 Cliff & The 5GB VRAM Wall

Autonomous AI agents in production face a severe dilemma: rely on remote APIs and freeze whenever rate limits (429s) or billing quotas hit, or run locally on modest homelab hardware with entry-level GPUs (e.g. 5GB–8GB VRAM) where modern 30B+ models cannot fit.

We recently tested AirLLM (layer-wise PCIe streaming) on a Dell PowerEdge server (6-core Xeon, 48 GB RAM, Quadro P2200 5GB VRAM) using Qwen3-30B-A3B-Instruct (30.5B total / 3.3B active params). While memory stayed under 0.6 GB, the physical bandwidth of PCIe 3.0 capped inference at 0.022 tokens/sec (45 seconds per token). Swapping 51 layer shards over the bus every token took 48 minutes for a single turn and crashed OpenClaw's turn timeout.

2. The Architecture: Asymmetric Dual-Engine Coupling

Rather than streaming 16 GB of weights back-and-forth across PCIe every token, the Frankenstein MoE decouples reflex speed from deep reasoning using an asymmetric division of labor:

+-------------------------------------------------------------------------------+ | DELL POWEREDGE HOMELAB WORKHORSE | | | | [ NVIDIA QUADRO P2200 5GB VRAM ] [ 48 GB DDR4 ECC HOST RAM ] | | --------------------------------- --------------------------- | | * 1.5B Fast Reflex Drafter (1.1 GB) * 30.5B MoE Reasoning Cortex | | (Qwen2.5-Coder-1.5B @ 55+ tok/s) (Qwen3-30B-A3B IQ4_NL, 16.3GB)| | * P2200 Headroom (~3.9 GB Free) * 3.3B Active Params / Token | | (Houses KV activation caches) (Zero PCIe weight thrashing) | +-------------------------------------------------------------------------------+ ^ | PCIe 3.0: Tiny Activation Vectors only (~10 KB) v +-------------------------------------------------------------------------------+ | OPENCLAW AUTONOMOUS AGENT JAILED RUNTIME | | * Local Port 5002: Fast Reflex Lane (commit messages, syntax, triage) | | * Local Port 5001: Heavy Reasoning Cortex (architecture, multi-file code) | +-------------------------------------------------------------------------------+
  • Reflex Drafter: A 1.5B code model pinned 100% in VRAM answers instant sub-second tasks at ~55 tok/s.
  • Reasoning Cortex: The 30.5B MoE sits resident in DDR4 RAM. Because it is a sparse MoE, the 6-core Xeon only computes 3.3B active parameters per token, yielding ~8 to 12 tok/s without PCIe weight thrashing.

5. Upstream Code Patches Applied in the Wild

During the live bare-metal evaluation, two upstream library bugs were identified and patched:

# Patch 1: transformers 4.57.6 positional argument fix in airllm_base.py
- self.hf_quantizer.create_quantized_param(self.model, state_dict[param_name], param_name, self.running_device, state_dict)
+ self.hf_quantizer.create_quantized_param(self.model, state_dict[param_name], param_name, self.running_device, state_dict=state_dict)

# Patch 2: accelerate Params4bit tensor eviction guard
